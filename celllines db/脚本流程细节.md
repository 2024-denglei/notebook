## 步骤 5：加载 EFO 本体（NCIt→EFO 映射）

`@e:\bigbio\sdrf-cellline-metadata-db\cellosaurus_full_extract.py:881-884`

- 调用

    - **Case 2**：EFO 内嵌的 MONDO term 同时有 `xref: NCIT:` 和 `xref: EFO:` → 间接映射
        
- 建立 `dict[NCIT_ID → EFO_ID]`（3020 条映射）
    
- **用途**：将 Cellosaurus 疾病的 NCIt accession 转换为 EFO accession
    

## 步骤 6：加载 UBERON 本体 + 构建 organism part 解析器

`@e:\bigbio\sdrf-cellline-metadata-db\cellosaurus_full_extract.py:886-892`

### 6a. 解析 UBERON OBO（parse_uberon_obo，第 95~139 行）

- 遍历 `uberon.obo` 的每个 `[Term]` 块
    
- 分别提取三个映射：
    
    - `id_name`：UBERON_ID → 名称
        
    - `id_isa`：UBERON_ID → is_a 父级列表
        
    - `id_partof`：UBERON_ID → part_of（BFO:0000050）父级列表
        
- 跳过 `is_obsolete: true` 的条目
    

### 6b. 构建解析缓存（build_organism_part_resolver，第 229~247 行）

- 对 UBERON 中**每个 term**，调用 
    
    _resolve_single 做 6 阶段解析：
    
    - **Phase 1**：自身是 organ（通过 is_a 链能到达 `UBERON:0000062`）→ 返回自身
        
    - **Phase 2**：自身是 tissue 或 bodily fluid → 返回自身
        
    - **Phase 3**：自身是 organ part → 返回自身
        
    - **Phase 4**：沿 part_of 链向上走，找到第一个 organ → 返回该 organ
        
    - **Phase 5**：沿 part_of 链向上走，找到第一个 tissue/fluid/organ_part → 返回
        
    - **Phase 6**：都找不到 → 返回自身
        
- 最后对名称做 `_UBERON_NAME_NORM` 规范化（如 `camera-type eye` → `eye`）并转小写
    
- 结果：`dict[UBERON_ID → organism part 名称]`（14971 条）

# 二、解析 Cellosaurus 原始数据（第 894~896 行）

`@e:\bigbio\sdrf-cellline-metadata-db\cellosaurus_full_extract.py:894-895`

调用 

parse_cellosaurus_file_full(cellosaurus, bto_data, cl_type_data)

### 解析过程（parse_entry，第 562~640 行）

解压 `cellosaurus.txt.gz`，以 `//\n` 分割每个细胞系条目，对每个条目逐行解析：

|行前缀|提取内容|存储字段|
|---|---|---|
|`ID`|细胞系名称|`cellosaurus name`|
|`AC`|Cellosaurus accession (如 `CVCL_0001`)|`cellosaurus accession`|
|`SY`|同义词，用 `;`  分割|`synonyms`|
|`DR CLO`|CLO accession (如 `CLO_0003684`)|`CLO accession`|
|`DR BTO`|BTO accession → 查 bto_data 获取 BTO 名称和额外同义词|`bto cell line`, `synonyms`|
|`OX`|物种信息 → 调用 parse_cellosaurus_taxonomy 用正则提取学名和 tax ID|`organism`（小写）|
|`SX`|性别 → 只接受 `male/female/intersex/mixed sex`|`sex`|
|`AG`|年龄（如 `25Y`, `Adult`, `Fetus`）|`age`|
|`CC Population`|祖先/族群（如 `Caucasian`）|`ancestry category`|
|`DI NCIt`|疾病 → 正则提取 NCIt accession 和疾病名|`disease`, `disease_ncit_accession`|
|`CC Derived from site`|采样部位 → 调用 get_sampling_site 提取部位名、UBERON ID、类型(In situ/Metastatic)|`sampling site`, `sampling_site_uberon`, `sampling_site_type`|
|`CC Cell type`|细胞类型 → 调用 get_cell_type 提取 CL ID，再查 cl_type_data 获取名称|`cell type`|

**总共解析出 167,186 条细胞系**。

# 四、转换为输出格式（第 912~917 行）

`@e:\bigbio\sdrf-cellline-metadata-db\cellosaurus_full_extract.py:912-917`

对每个 entry 调用 

convert_to_full_entry（第 679~763 行），做以下转换：

### 4a. Cell line 名称解析（第 693~702 行）

- 取 entry 的 CLO accession → 在 `clo_map` 中查找 CLO 标准名称
    
- 如果找到 → 用作 `cell line`；否则 → `not available`
    

### 4b. 疾病 MONDO/EFO accession 映射（第 704~714 行）

- 取 entry 的 `disease_ncit_accession`
    
- 在 `ncit_to_mondo` 中查找 → `disease_mondo_accession`
    
- 在 `ncit_to_efo` 中查找 → `disease_efo_accession`
    

### 4c. Organism part 解析（第 716~722 行）

- 取 entry 的 `sampling_site_uberon`（如 `UBERON:0002048`）
    
- 在 `uberon_resolver` 缓存中查找 → 获得解析后的 organism part 名称（如 `lung`）
    

### 4d. Age + Developmental stage 处理（第 746~756 行）

- 取原始 `age` 字段：
    
    - **含数字**（如 `25Y`, `10FW`）：
        
        - `age` → 调用 
            
            normalize_age_format 规范化格式（`FW→W`, `55-59Y→55Y-59Y`）
            
        - `developmental stage` → 调用 
            
            estimate_developmental_stage：
            
            - 含 `FW/FD/FM` → `late embryonic stage`
                
            - `≥18Y` → `adult`
                
            - `3-17Y` → `juvenile stage`
                
            - `<3Y` → `infant`
                
            - `<28D` 或 `<4W` → `neonate`
                
            - 其余月/周/天 → `infant`
                
    - **纯文字**（如 `Adult`, `Fetus`, `Neonate`）：
        
        - 在 `_CELLOSAURUS_DEV_STAGE_MAP` 中查找（小写匹配）
            
        - 如 `adult→adult`, `fetus→late embryonic stage`, `neonate→neonate`
            

### 4e. None 值处理（第 758~761 行）

- `sampling site`、`organism`、`organism part` 为 None 时替换为 `not available`
    

### 4f. 填充固定字段

- `Material type` = `"cell"`
    
- `curated` = `"not curated"`
